# Sayali Banode Makeup Artist - Website

A modern, responsive, luxury portfolio and booking website for **Sayali Banode Makeup Artist**, matching the design, typography, color palette, animations, and features of the live preview.

---

## 🚀 Quick Start (Zero Setup Needed)

You can view the website immediately without installing anything:
1. Open this folder in Windows File Explorer:
   `Downloads > sayali-banode-makeup`
2. **Double-click `index.html`** to open it directly in Chrome, Edge, or your default browser!

---

## ✨ Features Included

- **Luxury Bridal Design System**:
  - **Playfair Display** editorial serif typography & **Inter** sans-serif body copy.
  - Metallic gold gradients (`#D4AF37` to `#E8D5A1`), champagne/rose-tinted backgrounds, and glassmorphic card effects.
- **Dark & Light Mode Switcher**:
  - Seamless toggle with persistent user preference in `localStorage`.
- **Top Reading Progress Bar**:
  - Gold progress indicator tracking scroll position across the page.
- **Dynamic Navbar**:
  - Changes from transparent to frosted dark-glass on scroll.
  - Mobile responsive hamburger menu drawer.
- **Hero Section**:
  - Full-screen high-res bridal imagery with gradient overlay and dual CTAs (*View Portfolio* and *Book Appointment*).
- **About the Artist**:
  - Artist profile portrait, bio, philosophy, and trust metric badges (5+ Years, 500+ Happy Brides, 100% Luxury Brands, 5.0 ★ Rating).
- **9 Specialized Services**:
  - Bridal Makeup, Engagement Makeup, Reception Makeup, Party Makeup, HD Makeup, Airbrush Makeup, Editorial Makeup, Fashion Shoot, Hair Styling with hover animations.
- **Filterable Portfolio & Lightbox Modal**:
  - Filter tabs: *All, Bridal, Reception, Party, Editorial, Glam*.
  - Click any image to open full-screen dark-mode Lightbox with caption and backdrop-close.
- **Client Testimonials Carousel**:
  - 5-star real reviews with previous/next controls, active pagination indicator dots, and auto-rotation.
- **Instagram Beauty Journey Showcase**:
  - Direct connection to `@sayalibanodemakeup`.
- **Interactive Booking Form**:
  - Captures Full Name, Phone, Email, Event Date, Service selector, and Requirements.
  - Interactive toast feedback on submission.
- **Contact Info & Floating WhatsApp Action**:
  - Direct Phone, Email, Location cards.
  - Fixed bottom-right circular WhatsApp quick chat button (`https://wa.me/917030477747`).
